# Roadmap

## Milestone 1: Foundation

- Stabilize builds on macOS and Windows.
- Add file/folder pickers for custom scans, large files, and duplicate scans.
- Add confirmation dialogs for delete, quarantine, restore, and permanent delete.
- Expand SQLite settings and history pages.

## Milestone 2: Windows Product Readiness

- Validate Defender and AMSI integrations on Windows 10/11.
- Add scheduled task provider and proxy/hosts/browser policy inspectors.
- Add publisher/signature metadata checks.
- Add installer with Velopack, signed binaries, auto-update feed, and crash reporting.

## Milestone 3: Commercial Security Program

- Build secure rule update service.
- Establish malware research pipeline and false-positive review workflow.
- Add tamper-resistant Windows service.
- Build signed minifilter driver only after threat model, certification, HLK testing, and rollback plan.
- Add enterprise logs, privacy controls, and compliance review.
