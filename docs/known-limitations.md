# Known Limitations

- No certified kernel driver is included.
- Defender and AMSI require Windows validation.
- Publisher metadata and Authenticode checks need implementation.
- Browser history/cookie parsing is not enabled by default because it can be invasive and browser-specific.
- Cleanup execution UI is not wired yet; scans are review inventory only.
- Quarantine UI currently lists records; confirmation dialogs and restore/delete buttons are next.
